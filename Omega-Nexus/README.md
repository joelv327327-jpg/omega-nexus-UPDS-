# Omega Nexus

## Descripción del proyecto

Omega Nexus es una página web interactiva desarrollada como proyecto integrador de la materia Diseño Web II. Su objetivo es ofrecer una plataforma moderna, dinámica y fácil de utilizar para organizar, visualizar, buscar y consultar contenido dentro de un catálogo digital temático.

La plataforma contará con herramientas de búsqueda, filtros, organización por categorías y visualización detallada de los elementos. Además, tendrá un diseño responsive para adaptarse correctamente a computadoras, tablets y dispositivos móviles.

## Referencia de Paginas Web Investigadas

IGDB (Internet Game Database) – igdb.com
Base de datos muy completa de videojuegos: fichas, plataformas, géneros, fechas de lanzamiento, desarrolladores, covers, trailers, etc.
HowLongToBeat – howlongtobeat.com
Especializada en tiempos de duración de los juegos (historia principal, completado al 100%, etc.), además de información básica de cada título.
Metacritic – metacritic.com
Muestra puntuaciones de críticos y usuarios, resúmenes, trailers, fechas y fichas de casi todos los videojuegos.
RAWG – rawg.io
Gran base de datos de juegos con filtros avanzados, capturas, requisitos, plataformas, valoraciones y recomendaciones.
