# Estructura de carpetas

Estructura de carpetas organizada (por ejemplo: `/css`, `/js`, `/img`, `/assets`).

Ejemplo sugerido:
- `/css` — estilos CSS
- `/js` — scripts JavaScript
- `/img` — imágenes y gráficos
- `/assets` — recursos adicionales (fuentes, íconos, etc.)

Mantener una estructura consistente facilita la navegación y la colaboración.
